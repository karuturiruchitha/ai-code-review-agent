# Code Review Dashboard

React.js dashboard showing codebase health trends over time.

## Features
- Code Health Score per PR (0-100 gauge chart)
- Issue breakdown by type (Critical / Warning / Suggestion)
- Historical trend line showing if codebase is improving
- File-level drill down — which files have most issues
- Weekly summary report

## Stack
- React.js
- Chart.js for visualizations
- Axios for API calls to FastAPI backend
- MySQL for data storage
